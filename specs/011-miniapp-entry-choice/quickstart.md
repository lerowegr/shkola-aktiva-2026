# Проверка

1. `npm run check` на отдельной базе `sha_test`, затем `npm run dev`.
2. Открыть `/tg` в Telegram новичком: два действия, анкета не появляется.
3. Выбрать тест, ответить и отправить: результат и «Зарегистрироваться на ША».
4. Повторно открыть тест: тот же результат, второй попытки нет.
5. Заполнить профиль через кнопку результата: результат сохраняется.
6. Выбрать сайт новичком/зарегистрированным/организатором: главная/кабинет/кабинет организатора.
7. Прямая ссылка уведомления открывает указанный раздел.
8. На 375px нет горизонтальной прокрутки; проверить клавиатуру, загрузку и ошибку связи.
