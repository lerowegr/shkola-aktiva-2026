# Решения

- Выбор в `/tg` работает с главной кнопки приложения Telegram и из сообщения бота. Используем существующие `webApp`-кнопки.
- Отдельная страница переиспользует `GameShaTest`. Альтернатива `/cabinet/games/quiz` потребовала бы исключения для страницы внутри закрытого кабинета.
- Без знакомства разрешён только тест, его POST требует сессии. Регистрация для отбора остаётся обязательной.
- Прямые ссылки имеют приоритет; внешние адреса, обратные слеши и управляющие символы как цель запрещены.
