# Данные

Миграций нет. `User` и сессия создаются по проверенной подписи Telegram.
Пустое `User.onboardedAt` не мешает тесту; анкета по-прежнему требует профиль.
`QuizAttempt` уникальна по сезону и пользователю, а также Telegram. Регистрация не меняет попытку.
Клиент получает вопросы без `correct` и итоговые `score/total`.
