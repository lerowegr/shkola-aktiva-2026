# Переходы и доступ

- `/tg`: авторизация → выбор.
- `/tg?screen=test`: авторизация → `/test`.
- `/tg?screen=site`: авторизация → `/` для новичка, `/cabinet` для зарегистрированного, `/staff` для организатора.
- `/tg?to=<внутренний путь>`: прямой переход с приоритетом над `screen`; внешние пути не принимаются.
- `/test`: сессия обязательна, знакомство нет. Без сессии → `/login?from=/test`.
- POST `/api/cabinet/test/submit`: прежняя схема ответов, сессия обязательна, временный пароль сменён, профиль необязателен.
- Кнопка результата: новичок → `/cabinet/welcome`, зарегистрированный → `/cabinet`, организатор → `/staff`.
