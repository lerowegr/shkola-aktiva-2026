# План

- renderer служебной панели: Settings, editMessageText, обработка not modified, восстановление только при явной недоступности старого сообщения; сообщения в чате не удаляются.
- сервис чтения через loadBotSlot + loadReviewHistory, чистый форматтер и пагинация до 3400 UTF-16 единиц с сохранением суррогатных пар.
- добавить кнопку и обработчик предыдущих оценок; заменить ответы раздела на renderer, сохранив обычные ответы кандидату.
- проверить количество send/edit, восстановление, сетевые сбои, права истории, полноту текста и критериев; полные проверки и выкладка.
- добавить авторизованный GET для Excel, преобразование слотов по московской дате и рабочую книгу; проверить содержимое открытием созданного файла.

Конституция соблюдена: can(), существующие правила истории, private-чаты, audit оценок не меняется, поскольку чтение. Settings панели — техническое состояние интерфейса, не изменения отбора. Новый GET проверяет interviews.manage, фиксирует выгрузку в журнале; ролей нет. Telegram UI проверяется обработчиком с подменой транспорта, без сообщений реальным кандидатам. Доступ к нативному клиенту ранее дважды истёк по таймауту; живую проверку не считать выполненной без фактического результата.
