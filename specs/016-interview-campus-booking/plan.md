# План

1. Миграция: отдельная аудитория и счётчик самостоятельных переносов с учётом истории.
2. Чистые правила московского дедлайна, единый замок записи и расписания, один мастер/место, проверка пересечений.
3. Кабинет: выбор корпус/день/время, остаток переноса и точный дедлайн. Расписание организатора: неделя, один мастер, аудитория, ручное управление записью.
4. Напоминание накануне в 16:00, уведомление аудитории, аудит.
5. Тесты границ 18:00, параллельных запросов, исчерпания лимита, изменения аудитории и доступа; полный check, локальная проверка обоих кабинетов на 375px.
