# План

Существующий стек Nuxt/Vue/Nitro/Prisma, без новых зависимостей и миграций.

1. Чистое правило первичного дедлайна в rules.ts; применение в booking.ts и invitations.ts.
2. Чистый парсер вставленных строк таблицы (дата, с, до, корпус, мастер). Компонент показывает распознанное расписание; API проверяет права и передаёт нормализованные интервалы ядру.
3. Ядро импорта атомарно проверяет доступность мастеров и пересечения, повторно использует свободные слоты мастера за соответствующий день, создаёт недостающие; защищает записанных участников и журнал.
4. Прочитать исходный файл без изменения, сохранить расшифровку и сопоставления вне репозитория. Применить дополнения владельца; составить готовые строки для обычной формы сайта.
5. Обновить текст ручного приглашения, подсказки кандидата, напоминание мастеру за 5 минут. Проверить ограничения на сервере, тесты и экран 375px.
6. После проверок опубликовать код, импортировать через авторизованный сайт и открыть этап раньше дедлайна понедельника; сверить результат чтением базы.

Конституция соблюдается: права через can/requirePermission, изменения с аудитом, единый поток, оценки не разглашаются, Москва/русский/мобильный экран. Учётные данные и исходная занятость в git не помещаются.
