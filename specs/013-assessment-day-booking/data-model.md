# Данные

AssessmentSession — время дня, faculties[], reserve, capacity, снимок invited. Несколько резервных слотов допускаются в один день; faculties=[] означает все факультеты только для резерва.

AssessmentInvite: sessionId — выбранное время либо техническая опора приглашения до выбора; answer=null означает время ещё не выбрано и не занимает место. invitedDay String? YYYY-MM-DD, invitedFaculty String? фиксируют доступные обычные времена. reserveQueued=true — ожидание/выбор резерва; reserveOffered=true — отдельное приглашение из очереди уже отправлено. GOING — бронирование sessionId. Старый RESERVE без очереди поддерживается как назначенный резервный сбор. Отмена/перенос освобождает место.

AssessmentGroup.faculty String? — факультет подгруппы, null только для исторических общих групп. Новая группа одного факультета получает его автоматически, при нескольких факультетах организатор выбирает явно.
