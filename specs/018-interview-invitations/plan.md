# План

1. Только ручная отправка по явному нажатию управляющего.
2. Предпросмотр и явная отправка, единый список адресатов без фильтра факультета, дедупликация; проверка актуальности перед доставкой.
3. Из расписания — сообщение и карточка; защищённая история предыдущих оценок с процентами и критериями.
4. Тесты адресатов/времени/повторов/прав и доступа к истории, check, мобильная проверка. Реальная рассылка — по выбранному владельцем времени.
