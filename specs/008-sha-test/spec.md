# Feature Specification: «Тест про ША» в кабинете

**Created**: 2026-10-08 · **Status**: Draft

**Input**: перенести Mini App «ША бот внешка» (тест «Насколько хорошо ты знаешь ША?») в личный
кабинет, в раздел мини-игр, вместо «Викторины». Переписать внутри сайта; анкету перед тестом не
спрашивать — данные из профиля; 36 результатов бота перенести и привязать по Telegram, бот выключить.

## User Scenarios

### US1 — Кандидат проходит тест (P1)
В «Мини-играх» — «Тест про ША»: 10 вопросов по одному на экран, варианты перемешаны, «Назад»
меняет ответ. В конце — только число баллов из 10, без правильных ответов; дальше — ссылки на
Telegram и ВК Школы. Попытка одна: вернувшись, человек видит свой результат, пройти снова нельзя.

### US2 — Прошедшие в боте не проходят второй раз (P1)
Кто прошёл тест в боте и входит на сайт через тот же Telegram, видит свой результат из бота.

### US3 — Организатор видит итоги (P2)
В «Админка → Тест про ША» рядом с вопросами: сколько прошли, средний балл, распределение баллов,
доля верных и среднее время по каждому вопросу, выгрузка CSV (ФИО, Telegram, балл, ответы, время).

## Requirements
- FR-001 Счёт считает сервер по своим верным ответам; верные ответы в браузер не уходят.
- FR-002 Одна попытка на человека за сезон (и на Telegram-аккаунт из бота).
- FR-003 Ответы хранятся снимком (текст вопроса, выбранный вариант, верно ли, время) — правка
  вопросов не портит прошлые результаты.
- FR-004 Тест не влияет на отбор и не входит в рейтинг мини-игр.
- FR-005 «Викторина» убирается из списка игр; задание дня «Викторина» остаётся (встроенный пул).
- FR-006 Вопросы — в «Админка → Тест про ША» (прежний редактор викторины); стартовый набор —
  10 вопросов бота.
- FR-007 Импорт результатов бота — скрипт: баллы, ответы по вопросам, время, профиль из формы бота.
- FR-008 CSV с личными данными — только с правом просмотра всех анкет.
- FR-009 375px; русский; время по Москве.

## Success Criteria
- SC-001 Тест проходится за ≈2 минуты на телефоне.
- SC-002 Ни один ответ сервера кандидату не содержит верных ответов до и после прохождения.
- SC-003 Все 36 результатов бота видны в итогах.
