# Допуск к собеседованию после ЦО

По новому решению владельца запись на собеседование доступна только с отправленной анкетой и AssessmentInvite.attended=true. Баллы ЦО и факультет на допуск не влияют; ручная явка имеет приоритет над ответом приглашения. Это заменяет прежнее правило отсутствия отсева перед собеседованием, но не удаляет анкеты, оценки или существующие записи. Проверка выполняется при показе свободных времён и внутри транзакции записи, включая ручное назначение организатором. Отмена остаётся доступна управляющему. Снятая отметка явки блокирует новые записи и самостоятельные переносы, без автоматической отмены старых записей.

Отдельный список ЦО не пройден для организаторов с просмотром всех анкет или распределением: каждый кандидат один раз, по выбранному дню; без выбора — по дню приглашения; очередь и старые ответы RESERVE — в резерве. Несколько разных резервных дат без выбранного времени не подменяются вымышленной датой: отдельный блок резерва без назначенного дня. Без приглашения — отдельный блок. Отмеченные пришедшими исключены. Будущие/сегодняшние дни не считаются завершёнными. В списке единая пометка ЦО не пройден, без детализации причин, ссылка на анкету и фильтр факультета. Все анкеты по-прежнему доступны во вкладке Все.
