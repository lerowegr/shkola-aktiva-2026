# План

Nuxt 4, Prisma 7 и существующие роли. Существующую запись Application переводим в SUBMITTED только по выбору организатора; дата — фактическая дата принятия, аудит явно называет организатора. Валидацию полей допускается обойти только для этого адресного действия по запросу владельца; недостающие ответы не подделываются. Данные ЦО и численность других кандидатов не меняются.

1. Расширить helper аудита поддержкой транзакции, атомарно обновить выбранный черновик и создать аудит с отметкой отсутствия ДЗ. Подсказанные ответы берём из существующего профиля, не перезаписывая ответов. Назначить мастера анкеты; при действительной ссылке создать сдачу и назначить мастера ДЗ.
2. Защищённый defineAction проверяет users.manage и applications.assign, соответствие факультета, дату и опубликованный снимок выбранного времени. После принятия вызвать существующее персональное inviteSession; при неуспехе честно сообщить результат и не рассылать другим.
3. Добавить действие в карточку человека в админке с явным подтверждением, выбором времени и предупреждением о состоянии ДЗ. Приглашение создаётся на день: место за кандидатом только после его выбора.
4. Тесты на sha_test: сохранение ответов, отсутствие/наличие ссылки, атомарный аудит, отсутствие прав, несоответствующий слот, повтор и уведомление только одному кандидату. Полный check и браузер 375 px.

Конституция I–VI: права и аудит обязательны; автоматические массовые рассылки и другие черновики не меняем; отсутствующее ДЗ и статус не фальсифицируем. Правило обычной кандидатской отправки сохраняется. Миграции и схемы БД не нужны.
