# Договор действия

POST /api/admin/people/accept-application: userId и sessionId. Только пользователю с users.manage и applications.assign. Принимает один черновик текущего сезона и приглашает только его; возвращает результат принятия, наличие ДЗ и результат приглашения. Сохранённые ответы не заменяются; журнал обязателен.
