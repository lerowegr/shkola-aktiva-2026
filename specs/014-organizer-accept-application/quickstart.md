# Проверка

На тестовой базе создать активного кандидата с черновиком и подходящий опубликованный сбор. В демо войти организатором, открыть человека, выбрать время, подтвердить. Проверить статус, сохранённые ответы, отсутствие фиктивного ДЗ, аудит, одно приглашение и отсутствие других получателей. Затем проверить ограничения, мобильный вид и npm run check.
