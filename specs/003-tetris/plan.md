# Plan: «Тетрис из пиксельных объектов»

**Feature**: `specs/003-tetris/spec.md` | **Constitution**: 1.0.0 (I–VI)

## Сверка с конституцией

- **III (Честный отбор)**: результаты не попадают в оценку, рейтинг — только
  своё место и число игроков (`lib/games/results.ts` без изменений логики);
  на отбор не влияет — подпись в карточке как у остальных игр.
- **V (Русский, Москва, телефон)**: весь текст на русском; время — длительность
  партии, пояс не важен; вёрстка на 375px без горизонтальной прокрутки.
- **VI (Проверка)**: чистая логика покрыта тестами, `npm run check` зелёный,
  экраны проходятся руками в браузере.
- Отступлений от принципов нет.

## Решения

- Стакан 10×20 (классика). Ширина поля ограничена и высотой окна, как у «Лови»
  (`max-w-[min(...)]`, соотношение 1:2), чтобы поле целиком влезало в экран.
- Партия — 120 с (`TETRIS_SECONDS` в `lib/games/rules.ts`, как `CATCH_SECONDS`).
  Переполнение — досрочный финиш, `durationMs` честный (сколько длилась).
- Очки: ряды 100/300/500/800 × уровень, уровень = `floor(lines / 10) + 1`;
  мягкое падение +1/клетка, жёсткое +2/клетка. `moves: null` (как у «Лови»):
  главный показатель — очки.
- Правдоподобие: `score 0…200 000` (с запасом выше идеальной игры за 2 мин),
  `duration 5 000…125 000`. Анти-спам по времени (`saveResult`) работает без
  изменений — упирается в честный `durationMs`.
- Случайность — 7-bag через `seeded`/`shuffled` из `app/games/rng.ts`;
  компонент — в `<ClientOnly>`, как остальные игры.
- Повороты — матрицы 4×4 + простые подножки
  `[(0,0), (-1,0), (1,0), (0,-1), (-1,-1), (1,-1)]` (достаточно для казуальной
  игры, SRS целиком не тянем).
- Отрисовка — DOM-сетка (200 клеток), а не canvas: обновление 1–10 Гц, проще
  доступность и `prefers-reduced-motion`. Клетка — цвет палитры + лёгкая
  пиксельная фактура CSS; иконки объектов — в легенде и призраке? Нет:
  иконки webp в 200 клетках — тяжело; фигуры различаются цветом бренда,
  объекты бренда — в оформлении экрана (фон, легенда, итог).
- Управление: клавиатура (←/→/↓/↑-поворот/Space-сброс/P-пауза) + ряд кнопок
  для телефона. Пауза при `visibilitychange`/`blur`, время игровое.

## Файлы

1. `app/games/tetris.ts` — чистый модуль: типы, ` PIECES`, `createTetris(rng)`,
   `tryMove`, `tryRotate`, `hardDrop`, `tick(state, dtMs)`, `ghostY`,
   `fallInterval(level)`. Стиль — как `catch.ts`/`memory.ts` (возврат нового
   состояния).
2. `app/games/tetris.test.ts` — тесты: появление фигуры, движение/стены,
   поворот с подножкой, фиксация, сгорание 1–4 рядов и очки, уровень,
   7-bag (все 7 за мешок), топ-аут, тик 120 с.
3. `lib/games/rules.ts` — `TETRIS` в `GameKind`, `TETRIS_SECONDS = 120`,
   запись в `GAMES` (slug `tetris`, `better: "higher"`). `describeResult`
   уже умеет «N очков» — без изменений.
4. `prisma/schema.prisma` — `TETRIS` в enum `GameKind` + миграция
   (`npm run db:migrate -- --name tetris-game`).
5. `app/components/game/Tetris.vue` — экран игры (таймер tick через rAF,
   кнопки, пауза, легенда).
6. `app/pages/cabinet/games/[game].vue` — ветка `GameTetris`;
   `app/pages/cabinet/games/index.vue` — `LOOK.TETRIS` + текст «четыре игры».

Сервер (`result.post.ts`, `games.get.ts`) менять не надо: `z.enum(GAME_KINDS)`
подхватит новый вид сам.

## Риски

- Миграция enum на проде: значение только добавляется — безопасно, отката
  не требует.
- DOM 10×20 на слабых телефонах: 200 узлов статично, меняется классами —
  приемлемо; проверить руками.
