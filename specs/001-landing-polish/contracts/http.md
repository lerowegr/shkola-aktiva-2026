# HTTP-контракты: Доработки лендинга

Все изменяющие запросы проходят `server/middleware/origin.ts` (свой адрес) и пишутся в журнал.

## POST /api/admin/site/images — загрузить фото

- Право: `content.manage`. Тело: `multipart/form-data`, поле `file` (одно изображение).
- Не через `defineAction`: файл в JSON не завернуть (как `POST /api/cabinet/homework`);
  проверка права — первой строкой.
- Ответ 200: `{ ok: true, image: { id, width, height } }`
- Ответ 200: `{ ok: false, message }` —
  - нет файла: «Выберите фото.»
  - больше 15 МБ: «Фото больше 15 МБ — уменьшите его или выберите другое.»
  - HEIC: «Фото в формате HEIC — сохраните его как JPEG …»
  - не изображение: «Это не фото. Подойдут JPEG, PNG или WebP.»
- 403 без права. Журнал: `content.image_upload`.

## POST /api/admin/site/save — сохранить тексты (существующий, расширен)

- Право: `content.manage`. Тело — документ `SiteContent` (см. data-model.md).
- Новые отказы: «Фото не найдено — загрузите его заново.» (ссылка на несуществующий id).
- Ответ 200: `{ ok: true, message }` — «Сохранено. Сайт уже обновился.» / «Изменений нет.»
- Журнал: `content.update` — `{ sections, label, removedImages }`.

## GET /api/admin/site (существующий, расширен)

- Право: `content.manage`.
- Ответ: `{ content, defaults, images: Record<id, { width, height }> }` — все фото сезона,
  для превью в форме.

## GET /api/site (существующий, расширен)

- Публичный. Ответ: `{ season, content, images: Record<id, { width, height }> }` — только
  фото, на которые ссылается документ (для `srcset` и пропорций без прыжков макета).

## GET /media/site/:id/:width.webp — отдать фото

- Публичный. `width` ∈ {480, 960, 1600}; иначе 404.
- 200: `image/webp`, `Cache-Control: public, max-age=31536000, immutable`,
  `X-Content-Type-Options: nosniff`.
- 404: нет такого фото или варианта (например, удалено уборкой).

# UI-контракты

## LandingCtaPanel

- Входы: состояние кнопки (`landingCta`), дата закрытия анкеты.
- Показывает: живую точку (только если анкета открыта), строку состояния, «осталось N
  дней» (по Москве; «последний день» в день закрытия; нет даты — без строки), кнопку.
- Одинакова на первом экране и в финале.

## Маскот со следящими глазами

- Входы: имя маскота из набора с известными координатами глаз.
- Зрачки смотрят на указатель или последнее касание; без указателя — на главную кнопку.
- «Уменьшить движение»: зрачки неподвижны, без прыжков.
