# Data Model: Доработки лендинга по отзыву

## SiteImage (новая таблица `site_images`)

Фотография, загруженная организатором для лендинга.

| Поле | Тип | Правила |
|---|---|---|
| id | cuid | ключ; входит в адрес `/media/site/<id>/<ширина>.webp` |
| seasonId | string | сезон, к текстам которого относится; каскадное удаление |
| storageKey | string | случайный ключ имени файлов в `UPLOADS_DIR/site/` |
| width, height | int | размеры мастера (до 2400 px по большей стороне) |
| bytes | int | суммарный размер файлов вариантов |
| createdById | string? | кто загрузил (журнал — отдельно) |
| createdAt | datetime | для уборки: «без ссылок и старше часа» |

Варианты файлов: `<key>-480.webp`, `<key>-960.webp`, `<key>-1600.webp`, `<key>-master.webp`.
Ширина варианта не больше исходной (маленькое фото не растягивается).

## SiteContent.data (документ JSON, схема в `lib/site/content.ts`)

### Новое: ссылка на фото — `PhotoRef`

```text
{ id: string (cuid), alt: string ≤ 160 }
```

`alt` — что на фото, для незрячих; пустой допустим (тогда фото считается декоративным).

### Раздел `people` (вместо `roles`)

```text
people: {
  title: string ≤ 80              — по умолчанию «Люди Школы»
  items: Person[] ≤ 60
}
Person: {
  name: string 1..60               — обязательно
  role: string ≤ 60                — подпись: кто какая роль
  photos: PhotoRef[] ≤ 8           — первое фото — обложка
}
```

Пусто (нет людей) → раздел не показывается. Человек без фото → маскот вместо фото.
Старый раздел `roles` из сохранённых данных отбрасывается при чтении.

### Раздел `venue` — добавлено

```text
photos: PhotoRef[] ≤ 12
```

Раздел показывается, если заполнены место, даты, текст **или** есть фото.

### Раздел `history` — изменено

```text
items: HistoryItem[] ≤ 40          — было ≤ 12
HistoryItem: { year, title, text, photo: PhotoRef | null }
```

На главной — 3 события с наибольшим годом (число из начала строки года; без числа — в
конце); полный список — в таймлайне по годам.

### Без изменений

`hero`, `about`, `selection`, `program` (лицо — `title`, оборот — `text`), `faq`, `contacts`
(`telegram`, `vk`, `email` — ВКонтакте уже есть).

## Проверки при сохранении

- Каждый `PhotoRef.id` существует в `site_images` текущего сезона, иначе отказ:
  «Фото не найдено — загрузите его заново».
- После сохранения — уборка: `site_images` сезона без ссылок из документа и старше часа
  удаляются вместе с файлами.
- В журнал: `content.update` с изменёнными разделами и числом убранных фото.

## Загрузка

- Размер до 15 МБ; форматы, которые читает обработчик: JPEG, PNG, WebP (и GIF/AVIF/TIFF —
  берётся первый кадр). HEIC — понятный отказ с подсказкой.
- В журнал: `content.image_upload` (id, размеры).
