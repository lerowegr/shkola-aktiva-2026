# Quickstart: проверка доработок лендинга

## Подготовка

```bash
npm install            # добавятся sharp и simple-icons
npm run db:migrate -- --name site_images
npm run db:demo        # примеры людей, программы, истории (с пометкой «пример»)
npm run dev
```

Вход организатора — `npm run db:preview-accounts`, логин `admin` (при
`NUXT_PUBLIC_PREVIEW_LOGINS=true`) или владелец из `OWNER_EMAIL`.

## Сценарии

1. **Выделение текста (US1, SC-001)** — на главной 20 раз нажать, дважды кликнуть и долго
   коснуться (375px) 3D-объектов и фона первого экрана → текст не выделяется; подзаголовок
   выделяется специально.
2. **Плашка заявки (US1)** — на первом экране и в финале видна «наклейка» со строкой
   состояния, «осталось N дней» и кнопкой; при открытой анкете — живая точка.
3. **Люди (US2, SC-003)** — Админка → Сайт → «Люди»: добавить человека, загрузить 5 фото
   (одно HEIC — понятный отказ), подпись роли, сохранить → на главной тёмная секция
   «Люди Школы», лента едет, при наведении/касании замирает, у карточки листаются фото.
   Удалить человека и сохранить → через час его фото уходят уборкой.
4. **Программа (US3)** — карточки парят; клик, касание, Enter и пробел переворачивают к
   описанию и обратно.
5. **История (US4, SC-004)** — 30 событий в админке → на главной 3 последних и «Вся
   история»; таймлайн на весь экран, переход к году, Esc возвращает на то же место.
6. **Место (US5)** — 4 фото места → листаются вместо плитки; без фото — прежний вид.
7. **Перебивка (US6)** — прокрутка от «Итогов» к «Программе»: экран замирает, объекты
   собираются в стикер; на телефоне и при «уменьшить движение» — неподвижный стикер.
8. **Вопросы (US6)** — вопросы появляются по очереди, ответы раскрываются плавно.
9. **Финал (US6)** — маскоты смотрят на курсор/палец, прыгают при наведении на кнопку.
10. **Подвал (US6)** — заданы Telegram и ВК → обе ссылки со значками.

## Общие проверки

- `npm run check` зелёный.
- 375 / 768 / 1280: нет горизонтальной прокрутки (SC-006).
- Lighthouse главной (моб.): первый экран не медленнее, чем до доработок (SC-005).
- Журнал: загрузка фото и сохранение текстов записаны.
