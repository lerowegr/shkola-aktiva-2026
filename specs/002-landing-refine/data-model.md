# Data Model: Вторая итерация доработок лендинга

Новых данных, таблиц и полей нет. Разделы берут то же, что сейчас: `SiteContent.history`,
`SiteContent.people`, `SiteContent.program` (`lib/site/content.ts`). Ниже — производные
структуры, которые живут только в браузере.

## Sticker (`app/landing/stickers.ts`)

Наклейка коллажа перебивки; картинка — `public/brand/stickers/<name>.webp`.

| Поле | Правило |
|---|---|
| `name` | имя картинки; уникально; `logo` — последний в списке (ложится поверх) |
| `h` | высота картинки к ширине — для проверки, что наклейка в рамке |
| `rotate` | наклон в градусах |
| `narrow` | `{ x, y, w }` на телефоне (коллаж квадратный), `null` — не показывать |
| `wide` | `{ x, y, w }` от 640 px (коллаж 16:10) |

`x`, `y` — центр, `w` — ширина, всё в процентах коллажа; наклейка не вылезает за коллаж
больше чем на 4% (тест). Порядок в списке — порядок появления.

## Ribbon (`app/landing/ribbon.ts`)

| Поле | Смысл |
|---|---|
| `offset` | смещение дорожки, px, всегда в [0, period) |
| `period` | ширина одной копии списка, px |
| `velocity` | текущая скорость, px/с: автоход, инерция после броска |
| `idleSince` | когда последний раз трогали; через 4 с скорость возвращается к ходу |

Переходы: «едет» → (наведение / касание / колесо / фокус) → «держат» → (отпустили) →
«инерция» → (через 4 с без касаний) → «едет».
