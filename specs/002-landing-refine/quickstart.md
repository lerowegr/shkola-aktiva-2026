# Quickstart: проверка второй итерации лендинга

## Подготовка

```bash
npm run db:demo        # примеры людей, программы и истории (с пометкой «пример»)
npm run dev
```

Чтобы увидеть раскрытие истории, в админке «Сайт → История» должно быть больше 6 событий
(демо даёт несколько; добавить до 30 для SC-002).

## Сценарии

1. **Перебивка (US1, SC-001)** — пролистать от «Отбора» вниз: когда перебивка поднялась на
   треть экрана, наклейки по одной шлёпаются с пружинкой, сверху ложится логотип, соседи
   вздрагивают; всё за ~1,5 с, плавно и при быстрой прокрутке. Уйти выше и вернуться —
   проигрывается снова. Телефон 375px — наклейки в коллаже, синий маскот под логотипом
   виден. DevTools → Rendering → «prefers-reduced-motion: reduce» — готовый коллаж.
   Мышью навести на наклейку — приподнимается.
2. **История (US2, SC-002)** — на компьютере линия посередине, годы и тексты чередуются,
   точки загораются по прокрутке; «Вся история · ещё N» раскрывает остальные ниже, ряд
   годов переводит к нужному; «Свернуть» возвращает к началу раздела. 375px — линия слева,
   без горизонтальной прокрутки.
3. **Полоса прокрутки (US3, SC-004)** — на главной нет системной полосы (Safari, Chrome,
   Firefox); при прокрутке справа появляется маскот на линии и прячется в покое; его можно
   тянуть мышью, клик по линии переносит. Колесо, тачпад, PageDown/Space, якоря меню
   работают. В кабинете — тонкая полоса в цветах бренда. На телефоне маскот не мешает
   касаниям у правого края.
4. **Лента людей (US4, SC-003)** — потянуть ленту мышью и пальцем в обе стороны — шва нет;
   тачпадом по горизонтали — листается, вертикальная прокрутка страницы не ломается;
   отпустить — через ~4 с лента снова едет. Свайп по фото с несколькими снимками листает
   фото. Короткий клик по стрелке фото работает. Tab по карточкам — фокус не уходит за
   край.
5. **Программа (US5)** — карточки заметно покачиваются вразнобой; при прокрутке через
   раздел расходятся и сходятся; перевёрнутая карточка стоит; тексты соседей не
   перекрываются.
6. **Проверки** — `npm run check` зелёный; 375px — ни один раздел не даёт горизонтальной
   прокрутки (SC-005); Lighthouse мобильный — первый экран не хуже прежнего (SC-006).
7. **Попутная правка «Отбора»** — на 375px заголовки карточек этапов целиком в карточке
   («Собеседование» раньше обрезалось): размер заголовка
   `text-[clamp(1.75rem,7.5vw,2.25rem)]` в app/components/landing/Selection.vue.
