# Implementation Plan: Вторая итерация доработок лендинга

**Branch**: `002-landing-refine` (без отдельной ветки, работа в `main`) | **Date**: 2026-10-02 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/002-landing-refine/spec.md`

## Summary

Пять доработок главной по второму отзыву владельца. Перебивка — «стикер-бомбинг»
(итерация 3; до неё сняты сборка из пикселей и 3D-монета): наклейки с белой обводкой по
одной шлёпаются на страницу с пружинкой, последним ложится большой логотип; ролик ~1,5 с
играет сам, когда секция поднялась на треть экрана, без закрепления. История —
вертикальный таймлайн с линией посередине и чередованием сторон, 6 свежих событий и
раскрытие остальных на месте. Своя полоса прокрутки на главной — маскот на тонкой линии;
в кабинетах — тонкий системный индикатор в цветах бренда. Лента людей листается
перетаскиванием и колесом, бесконечно, и сама едет дальше через 4 секунды. Карточки
программы парят сильнее и расходятся при прокрутке. Новых данных, API и зависимостей нет.
Решения и отвергнутые варианты — в [research.md](research.md).

## Technical Context

**Language/Version**: TypeScript 5 (strict), Node 24; Vue 3.5 SFC

**Primary Dependencies**: Nuxt 4, three.js 0.186, GSAP 3.15 (ScrollTrigger), Tailwind 4. Новых
нет.

**Storage**: не затрагивается — тексты и фото сайта те же (`SiteContent`, `SiteImage`).

**Testing**: Vitest — раскладка наклеек (`app/landing/stickers.ts`: логотип последний и
посередине, наклейки в рамке коллажа) и лента
(`app/landing/ribbon.ts`: заворот смещения, отличие нажатия от перетаскивания, затухание
скорости); ручная проверка по [quickstart.md](quickstart.md) на 375px и компьютере, с
«уменьшить движение».

**Target Platform**: браузеры телефонов и компьютеров (Chrome, Safari iOS 16+, Firefox,
Chrome на Windows), Telegram Mini App.

**Project Type**: веб-приложение Nuxt (фронтенд и сервер в одном проекте); фича только
клиентская.

**Performance Goals**: перебивка — 60 к/с при прокрутке на среднем телефоне; кадр
рисуется только при изменении прокрутки; первый экран главной не медленнее (SC-006) —
3D-перебивка грузится, когда до неё экран; лента — один `transform` на кадр.

**Constraints**: 375px без горизонтальной прокрутки; «уменьшить движение» — без
самодвижения; без JS — готовый коллаж; перебивка без WebGL;
прокрутка страницы колесом, тачпадом, клавишами, пальцем и якорями работает как у
браузера (свою прокрутку не подменяем).

**Scale/Scope**: 10 наклеек (~240 КБ webp вместе с логотипом);
до 60 людей в ленте; до 40 событий истории.

### Source Code (repository root)

```text
app/landing/
├── pixel-maps.ts             # пиксельные карты объектов (вынесены из voxel-scene)
├── voxel-scene.ts            # только первый экран: режим «сборка» убран
├── glass-objects.ts          # стеклянный объект из пиксельной карты
├── stickers.ts               # раскладка наклеек перебивки (телефон и широкий экран)
├── stickers.test.ts
├── ribbon.ts                 # лента: заворот, перетаскивание, колесо, инерция, автоход
├── ribbon.test.ts
└── support.ts                # без изменений
app/components/landing/
├── Interlude.vue             # стикер-бомбинг: коллаж, ролик GSAP по появлению
scripts/make-stickers.ts      # наклейки с обводкой → public/brand/stickers
├── History.vue               # вертикальный таймлайн, 6 + раскрытие, годы
├── People.vue                # лента на ribbon.ts вместо CSS-анимации
├── PhotoSlider.vue           # свайп по фото не уходит ленте
├── Program.vue               # сильнее парение, расхождение при прокрутке
└── Scrollbar.vue             # маскот-ползунок главной (новый)
app/pages/index.vue           # класс html для скрытия системной полосы, <LandingScrollbar>
app/assets/css/main.css       # тонкая полоса в цветах бренда; скрытие на главной
```

**Structure Decision**: существующая архитектура лендинга — чистые модули в `app/landing`
(как `cta.ts` с тестом), сцены three.js там же, компоненты разделов в
`app/components/landing`. Новых слоёв и серверного кода нет.
