# План

Существующие Nuxt/Vue/Nitro/Prisma; одна nullable колонка archivedAt в InterviewSlot. Без новых зависимостей.

- Чистые расчёты окон 45+5 и сопоставление старых записей новым слотам по порядку с минимальным суммарным сдвигом. Одинаковые мастер, дата, корпус обязательны.
- Проверка 5 минут во всех способах создания/назначения слотов; снятые слоты не участвуют в конфликтах и доступном времени.
- Отдельный режим пересчёта в существующей форме загрузки с предпросмотром и версией. Старые слоты/записи остаются для истории. Восстановление — обычное защищённое действие с аудитом.
- Срочные уведомления после успешного сохранения; отменённые booking keys исключают устаревшие напоминания.
- UI кандидата показывает остаток единственной перезаписи, причины запрета и скрывает сведения о мастере. Проверка DTO на утечки.
- Тесты окон, пяти минут, атомарности, гонок, переносов, неизменности счётчика и уведомлений; ручной браузер и 375px. Деплой, пересчёт из согласованных исходных окон через сайт, чтение базы для сверки.

Конституция соблюдается: права, аудит, единый поток, только Москва, оценки и контакты мастеров не выдаются кандидатам. Исходная занятость остаётся вне git.
