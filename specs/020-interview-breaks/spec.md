# Перерывы, пересчёт записей и понятная перезапись

1. Собеседование длится 45 минут. Между встречами одного мастера минимум 5 минут, в том числе при смене корпуса. Конец доступного окна не сдвигается: 08:30–13:20 вмещает пять встреч. Последовательные свободные учебные интервалы одного корпуса с промежутком до 10 минут объединяются в окно; обед и занятые периоды сохраняются.
2. Организатор может пересчитать заданные окна. Владелец разрешил сдвинуть уже записанных участников и уведомить участников и мастеров. Кандидат остаётся у своего мастера, в том же корпусе и дне. Если мест для существующих записей не хватает, весь пересчёт отклоняется.
3. Предпросмотр показывает количество новых, снятых слотов и изменяемых записей. Сохранение проверяет версию: новые записи/изменения расписания после предпросмотра требуют повторной проверки. Общий замок исключает гонки. Аудит — в той же транзакции.
4. Старые слоты снимаются с записи с сохранением истории. Изменённая запись отменяется и создаётся новая без расходования самостоятельной перезаписи; старые напоминания не доставляются. Снятые свободные слоты доступны организатору для восстановления после проверки перерывов.
5. Кандидат не получает имена, id и контакты мастера в API и интерфейсе выбора/записи. Мастер видит своё назначение.
6. После записи/самостоятельной перезаписи мастер получает срочное уведомление с кандидатом, датой, интервалом и адресом. При переносе прежний мастер также узнаёт об освобождении времени. Повторная отправка одной записи не дублирует уведомление.
7. Кандидату отдельно показан лимит «1 раз», остаток и дедлайн до 18:00 накануне. Кнопка «Перезаписаться» видна и объясняет недоступность после срока/использования. Сервер атомарно ограничивает одну попытку. Первичная запись сохраняет правила 02:00 для 2 ноября и 20:00 накануне остальных дней.
8. В расписании есть фильтр «Мастер отбора», совместимый с корпусом, факультетом, днём и «Только мои». Выбор сохраняется в query master.
9. Отдельное задание для новых участников резервных подгрупп: отправка 02.11.2026 в 08:00 МСК, только с явкой и отправленной анкетой, без записи и предыдущего приглашения. Список фиксируется при планировании, утром повторно проверяется допуск. Задание и результат — в журнале. Повтор не дублирует приглашения; срочная доставка начинается сразу после наступления срока. Пользователь явно разрешил эту отправку.
