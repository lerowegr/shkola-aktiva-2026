# План: напоминания об отборе

Дата: 2026-10-17. Спецификация: [spec.md](spec.md).

## Решение

Использовать текущий минутный проход Nitro и notify(), PostgreSQL / Prisma 7,
TypeScript, Vitest. Новых таблиц и ручек нет. Точка входа —
server/plugins/notification-worker.ts. Добавить lib/notifications/selection-reminders.ts
с генераторами для анкеты и ЦО. Ключи включают id этапа/группы и ISO-время события;
уникальность Notification(userId, key) защищает от дублей при нескольких процессах.

## Проверка конституции

I–II: новые ручки и изменения организаторов отсутствуют.
III: для анкеты stageState(), ЦО берётся только из notified.
IV: секретов и файлов нет. V: notify(), русский текст, явный Europe/Moscow.
VI: интеграционные проверки на sha_test, типы и линтер; браузерная проверка
при наличии локальной авторизованной сессии. Коммит и публикация не входят в задачу.
Проверка до и после проектирования: нарушений нет.
