# Платформа «Школа Актива 2026» — спецификация

Сайт мероприятия и система отбора участников. Здесь зафиксированы решения,
принятые до начала разработки. Меняются только осознанно — с правкой этого
файла.

## Части системы

1. **Внешний сайт.** О ША, история, как проходит, роли на проекте, место,
   даты, регистрация. Максимум движения: параллакс, 3D, сцены по скроллу.
2. **Кабинет кандидата.** Анкета → домашнее задание → собеседование →
   результат. Трекер этапов, мини-игры в ожидании, уведомления.
3. **Кабинет организатора.** По образцу «Кабинета мастера отбора»
   (sst-otbor-2026): мои анкеты, все анкеты (чужие — только чтение),
   оценка по критериям с расшифровкой баллов, маркеры, комментарий,
   автосохранение, переписка с кандидатами через бота, вкладки этапов под
   замком до их открытия.
4. **Тех.админка.** Люди и роли, конструктор анкеты и критериев, этапы и
   даты, тексты сайта, журнал действий, выгрузки.
5. **Дашборды.** Воронка, динамика заявок, прогресс проверки, распределение
   баллов, разброс оценок между мастерами, каналы.
6. **Telegram-бот, Mini App, PWA.** Один фронтенд в трёх оболочках.
   Уведомления в четырёх каналах: сайт (колокольчик), PWA-пуш, бот, Mini App
   (через сообщение бота с кнопкой на нужный экран).

## Принятые решения

| Вопрос | Решение |
|---|---|
| Стек | Nuxt 4 (Nitro-сервер) + Vue 3.5 + TypeScript + Prisma 7 + PostgreSQL 16 + grammY + zod + Tailwind 4 + GSAP. Тот же, что в `~/СНиМК/portal` и `~/ПК_Тасктрекер` |
| Отбор | **Единый поток.** Без деления на факультеты и направления; один пул мастеров, анкеты распределяются по нагрузке |
| Вход кандидатов | Telegram (код через бота, Mini App) + почта (одноразовый код) |
| Вход организаторов | Telegram + пароль, который человек задаёт сам по ссылке-приглашению |
| Роли | Настраиваются в админке из фиксированного списка прав (как в СНиМК). По умолчанию: мастер отбора, главный организатор, тех.админ |
| Сезоны | Всё привязано к сезону («ША 2026»). На следующий год — новый сезон, не новый код |
| Хостинг | Сервер за пределами РФ — согласовано с вузом. Cloudflare перед сайтом не ставим; перед запуском проверяем открываемость с российских мобильных сетей |
| Сроки | Регистрация откроется больше чем через месяц — делаем по порядку |
| Брендбук | Палитра и шрифты подключены (01.10), разбор — `docs/brand.md` |

## Порядок этапов

Сначала вся внутренняя часть по образцу шаблона, потом лендинг (решение
01.10).

1. ✅ Каркас: проект, база, вход, права, журнал, сезон и этапы.
2. ✅ Анкета и кабинет мастера: анкета кандидата с автосохранением,
   распределение по нагрузке, «Мои анкеты», «Все анкеты», оценка по
   критериям с маркерами и комментарием, управление датами этапов.
3. ✅ Сообщения и уведомления: бот, переписка с кандидатами, колокольчик,
   PWA-пуши, Mini App.
4. ✅ Домашнее задание («Центр оценки») и собеседования (слоты), решения по
   этапам и итоги.
5. ✅ Тех.админка (роли, люди, конструктор анкеты и критериев, рассылки,
   журнал) и дашборды. Тексты сайта переехали в этап 6 — их структура
   рождается из дизайна лендинга.
6. ✅ Лендинг с эффектами: 3D-объекты бренда, движение на прокрутке,
   тексты из админки, напоминание «анкета открылась».
7. ✅ Мини-игры: «Пары», «Пятнашки», «Лови» в кабинете, место среди
   кандидатов без имён, на отбор не влияют.
