# Этап 7 «Мини-игры» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Пока кандидаты ждут результатов этапа, в кабинете есть три короткие игры в стиле бренда: «Пары» (мемори с маскотами), «Пятнашки» (собрать стикер-логотип), «Лови» (ловить стеклянные объекты, уворачиваться от молний). Лучший результат и место среди кандидатов — без чужих имён.

**Architecture:** Правила каждой игры — чистые модули `app/games/*.ts` (состояние → ход → новое состояние, случайность через сид), покрыты тестами; компоненты только рисуют и передают ввод. Результат партии уходит на сервер; сервер проверяет правдоподобие (границы очков, время, не чаще, чем идёт партия) и считает лучший результат и место. Рейтинг — только среди кандидатов, без имён: «вы на 12 месте из 87».

**Spec:** `docs/specs/2026-09-28-sha-platform.md`

## Global Constraints

- Всё из `CLAUDE.md`. Кабинет говорит на «вы».
- Игры никак не влияют на отбор: результаты не попадают в карточки оценки и не видны мастерам. Это написано на странице игр.
- Чужие имена не показываются никому из кандидатов — только своё место и число игроков.
- Подделать результат можно (это браузер), но бессмысленно: призов нет. Сервер отсекает невозможное, а не ловит каждого.
- Управление: палец, мышь и клавиатура. Партия — до пары минут. Вкладка скрыта — «Лови» на паузе.
- Без звука. Вибрация — только в Telegram, где она штатная.
